# WearAppUpdater

WearAppStore (WearAppUpdater) is a premium, lightweight, standalone app store and package updater client built for Wear OS smartwatches.

## Features
- Standalone package updates directly on Wear OS smartwatches\n- Pitch Black AMOLED dark theme with custom borders\n- Round bezel layout padding to prevent text clipping\n- Automatic package detection with legacy com.example.* namespace detection\n- Sleek and responsive Compose UI

## Installation
Install directly via the [WearAppStore](https://github.com/ajimsjames/WearAppUpdater) client on your watch.

## Technical Details
- **Namespace**: `com.ajimsjames.wearappupdater`
- **Version**: `3.2.0`
- **Target OS**: Wear OS (API 30+)
